📷 스크린샷 자동 인식 (OCR)

인게임 "전체 스텟" 창 스크린샷을 올리면 숫자를 읽어 입력칸을 자동으로 채웁니다. 원본·대비·반전·우측확대 4패스 다수결로 인식. 인터넷 연결 필요(첫 1회 엔진 다운로드).
⚠️ 자동 인식은 정확하지 않을 수 있습니다 — 적용 전 아래 편집칸에서 값을 꼭 확인하세요.
📌 좋은 사진 = 정확한 인식
✅ "전체 스텟" 창이 열린 상태에서 캡처 (오른쪽 수치 목록이 보여야 함)
✅ 해상도 높을수록 좋음 — 전체화면 캡처도 OK, 하지만 글자가 클수록 정확 (창 모드보다 큰 화면 권장)
✅ 또렷하게 — 흐림·압축·반투명 오버레이 없이. PNG 권장(JPG 압축은 숫자 뭉갬)
✅ 스텟 창만 잘라서 올리면 가장 정확 (배경 노이즈 ↓)
⚠️ 한글 게임폰트 OCR이라 소수점·8↔6 등 가끔 틀림 → 아래 편집칸에서 꼭 확인 후 적용
📋 인식된 라벨 → 값 (수정 가능, 한 줄에 라벨: 값)
🔍 OCR 원본 텍스트 (참고용)

레벨 & 스텟 포인트

사용 0 / 총 0 남은 0
▶ "남은 포인트"는 인게임의 ⬢ 포인트 숫자를 그대로 입력 (현재 스텟에 이미 찍은 포인트가 반영된 경우)
▶ — 초기 세팅(0부터 분배)할 때 사용
▶ 기본 체력 50 / 치명타 공격력 110%는 자동 추가하지 않음 — "전체 스텟 스냅샷"의 체력·치명타 공격력(%) 칸에 직접 입력

기본 스텟 효과

힘 (STR) · 공격력 +1, 치명타 공격력 +0.1%
민첩 (DEX) · 공격력 +0.3%, 치명타 확률 +0.05%
생명력 (VIT) · 체력 +5, 회피 +0.03%, 물약 회복량 +0.5%
행운 (LUK) · 경험치 +0.2%, 드랍률 +0.2%

🧠 자동 최적화

최적화 목표
시작 상태
현재 입력된 스냅샷 수치 기준으로 기대 데미지(스킬 1타, 크리 확률 평균 반영)가 최대가 되도록 남은 포인트를 분배합니다. 크리 터진 한 방이 아니라 평균 한 타 기준이라 지속 사냥·DPS에 맞습니다. 보스·일반 몹 모두 최적 분배는 같습니다 — 보스 공격력%·스킬 피해량% 같은 상수 배수는 스텟 간 순위에 영향이 없기 때문. 수치를 바꾼 뒤 다시 눌러야 재최적화됩니다.

🎯 목표 공격력 역계산

목표 공격력
기준
원하는 공격력만 딱 맞추는 최소 포인트(힘·민첩 조합)를 찾습니다. 공격력에 영향을 주는 건 힘(플랫 +1)과 민첩(공격력 +0.3%)뿐이라 두 스텟만 씁니다. 목표를 넘기지 않는 조합은 존재하지 않을 수 있어(스텟이 정수 단위) 목표 이상 중 최소를 찾고, 동점이면 기대 데미지가 높은 쪽을 고릅니다. 남는 포인트는 생명력·행운에 자유롭게 쓰세요.

📋 전체 스텟 스냅샷

인게임 "전체 스텟" 창(오른쪽 패널)의 모든 수치를 그대로 입력하세요. 추가 포인트의 순수 기여분(delta)만 더해서 결과가 표시됩니다.
예(스크린샷 기준): 공격력 586.25, 체력 1562.99, 힘 223.39, 민첩 135.23, 생명력 28.05, 행운 296.66, 공격력% 50.17, 최종 공격력% 2.8, 치명타 확률% 6.76, 치명타 공격력% 132.34 …
